# DIP Project
Repository for DIP pre-processing and analysis scripts; current ongoing project.

Included scripts:
* DIP-edit-markers_with_OS.py     Editing the original errored trigger markings to align with the OS file.
* DIP-EEG-pre-processing.py       Processing the EEG data, including filtering.
* DIP-epoch_and_window_script.py  Script to epoch and extract the amplitude values in relevant ERP windows to analyse in R.
